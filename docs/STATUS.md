# Implemented scope and limits

This repository is a working development MVP for the supplied requirements. It does not implement every enterprise feature in the master prompt. The following distinctions are intentional and visible in the app.

| Area                 | Available now                                                                                           | Remaining before a commercial production claim                                                                              |
| -------------------- | ------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| Dashboard            | All 14 areas, responsive layout, searches, filters, shared components, detail dialogs                   | Custom dashboards, accessibility audit, full telemetry query UX                                                             |
| Identity             | Registration/login, organizations, four roles, project assignments, team accounts                       | Password recovery, verified email/invites, session revocation UX                                                            |
| Metadata             | Prisma/PostgreSQL, migration, JSON demo persistence, timestamps/indexes/constraints                     | Broad PostgreSQL integration/recovery validation and archival policy                                                        |
| Agent                | Local Node host measurements, enrollment, heartbeat, rotate/revoke, config download                     | Native installers, runtime/permission detection, signed updates, version rollout                                            |
| Metrics/logs/traces  | OTLP/HTTP JSON/protobuf gateway, project identity, live adapters and searches                           | Sustained storage load/recovery tests, advanced per-service/per-host dashboards                                             |
| Discovery            | JSON OTLP service metadata; manual app/database/container records                                       | Protobuf discovery, complete exporter metric mapping and live inventory reconciliation                                      |
| Infrastructure       | Real heartbeat CPU/memory/disk/uptime; hostmetrics collector configuration                              | Full process health, disk/network I/O history, Docker/Kubernetes inventory reconciliation                                   |
| Application/database | Sample views, manual inventory, live OTLP storage/query foundation                                      | Complete Node/Python/PHP/Java/.NET instrumentation packages; PostgreSQL/MySQL/SQL Server exporter validation; slow-query UI |
| Alerts               | Snapshot thresholds, pending/firing/recovery, deduplication, cooldown, silence, maintenance pause       | Query-based evaluation for all exporter metrics, organization-wide notification grouping, durable scheduler recovery        |
| Uptime               | Single-region public HTTP/HTTPS/TCP checks, latency, failure thresholds, certificate expiry capture     | Multi-region probes, long-run availability SLOs, durable scheduling, dedicated certificate UI                               |
| Billing              | Mock plan changes, trials, cancel-at-period-end, quotas, usage, simulated invoices, signed mock webhook | Razorpay/global provider adapters, real charges, proration, taxes, invoice PDFs, robust event ordering                      |
| Email                | Database local outbox; configurable SMTP with retries/history                                           | Provider delivery callbacks, production sender setup, validated volume limits                                               |
| Retention            | Shared 30-day backend configs; metadata cleanup for checks/deliveries                                   | Per-tenant physical plan retention, billing/audit archival policy                                                           |
| Deployment           | Compose, single-process built app, runbooks                                                             | HA, validated backups/restores, hybrid customer data plane licensing, offline enterprise, Helm charts                       |
| Tests                | API isolation/lifecycle tests, browser flows, ten-tenant API load runner                                | Sustained telemetry load, native installer matrix, disaster recovery, upgrade/rollback automation                           |

The environment's exact verification results are recorded in `verification/RESULTS.md`. Avoid treating sample charts, mock payment state, or a local control-plane benchmark as proof of production telemetry capacity.
